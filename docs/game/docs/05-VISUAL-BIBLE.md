# Nexo World — Visual Bible

## Style

**Stylized realism with believable human scale, clean modern materials, readable silhouettes, and restrained technology.**

## Player lock

The approved current player character is frozen. Do not change model, face, hair, clothing, scale, rig, materials, movement animations, shadow behavior, or collision dimensions.

## Characters

Hero agents use realistic adult proportions, modern work clothing, readable occupational details, natural posture, and restrained gestures.

Pedestrians use male/female variants, shared compatible rigs where practical, clothing color variation, modest height variation, different walk speeds, and controlled idle gestures.

Reject robots, helmets, armor, mannequins, capsule bodies, and clone crowds.

## Vehicles

Modern civilian sedan/hatchback family, believable proportions, closed cabin, transparent glass, visible interior, correct wheels, understated paint. No toy cars, futuristic neon, or copied brands.

## Architecture

Modern mixed-use district, human-scale ground floors, clear entrances, restrained facade repetition, readable landmarks, believable rooftop equipment.

## Roads and footpaths

- neutral asphalt with restrained roughness
- clear lane and crossing markings
- curbs with actual height
- concrete/paver footpaths
- subtle joints and wear
- curb ramps
- grass only at soil edges, tree pits, cracks, and landscaped strips

## Vegetation

Natural tree silhouettes, tapered trunks, real branching, non-spherical canopies, limited species palette, instanced grass clusters.

## Lighting

Late-morning daylight, neutral-warm sun, readable soft shadows, moderate ambient fill, subtle contact grounding.

## Rejection rules

Reject toy vehicles, robot citizens, cardboard facades, floating geometry, sphere trees, grass carpet over sidewalks, mixed photoreal/low-poly assets, excessive bloom, cyberpunk neon, and giant untextured surfaces.
