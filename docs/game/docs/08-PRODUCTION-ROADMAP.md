# Nexo World — Production Roadmap

## Phase 0 — Canonical alignment

Deliver:
- approved North Star
- approved GDD
- approved visual bible
- character lock
- approved vertical-slice mission

Exit: all agent tasks reference the same canonical files.

## Phase 1 — Baseline and stabilization

Deliver:
- system inventory
- performance baseline
- bug list
- frozen-system checksums
- manual smoke-test script

Exit: current prototype is reproducible and measured.

## Phase 2 — Hero vehicle

Deliver:
- Fable sedan redesign implemented in Blender
- nine approved QA renders
- node validation
- entry/drive/exit
- collision and chase camera
- safe exit

Exit: complete loop passes without changing the player.

## Phase 3 — Meridian District art pass

Deliver:
- main street
- plaza
- Operations Center
- Tool Row
- Infrastructure Annex
- roads, footpaths, vegetation, props

Exit: screenshots match the visual bible and performance remains within target.

## Phase 4 — Gameplay framework

Deliver:
- interaction registry
- mission director
- dialogue
- evidence
- decisions
- world-state reactions
- AAR

Exit: a mission advances from data rather than hard-coded scene chains.

## Phase 5 — Meridian Signal Failure

Deliver:
- three agents
- evidence chain
- three interventions
- validation
- district failure/recovery
- AAR

Exit: fresh player completes in 20–35 minutes; wrong choices recover; world changes.

## Phase 6 — Population and polish

Deliver:
- 8–16 active pedestrians
- male/female variants
- schedules
- crossings
- gestures
- ambient audio
- UI polish

## Phase 7 — Optimization and release candidate

Deliver:
- GLB optimization
- texture/mesh compression
- cross-browser tests
- adaptive quality
- save/load
- release checklist

## Expansion rule

Do not begin a second district until the first mission, vehicle loop, performance tiers, repeatable asset pipeline, and five external playtests pass.
