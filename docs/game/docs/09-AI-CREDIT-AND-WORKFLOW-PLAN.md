# AI Credit and Workflow Plan

Assumption: approximately $500 total credit across three permitted accounts.

## Suggested allocation
| Area | Budget |
|---|---:|
| Game and mission refinement | $40 |
| Fable visual bible and district concepts | $90 |
| Vehicle/environment art direction | $70 |
| Claude architecture and audit | $80 |
| Codex implementation and verification | $150 |
| Review, corrections, reserve | $70 |

## Discipline
- keep one canonical package shared across accounts
- separate audit, visual design, implementation, and QA
- do not duplicate tasks unless performing an explicit review
- preserve outputs inside the project docs
- follow each service’s terms and limits

## Credit-saving loop
Claude audits and plans → user approves → Fable supplies visual direction where needed → Codex implements a bounded task → Claude/ChatGPT review → browser/manual validation → next task.

## Stop conditions
Stop spending when scope changes mid-task, a required asset is missing, visual direction is unapproved, no measurable acceptance test exists, frozen systems are being rewritten, or output duplicates completed work.
