# Prototype Scope

## MVP

The first milestone is:

8 players can walk, see each other, enter one car, and interact with 5 world objects in a small city under the memory budget.

## Include

- third-person player controller
- one compact city district
- simple multiplayer room
- visible remote players
- one vehicle type
- enter and exit vehicle
- basic driving
- simple interact button
- 5 interactable objects
- basic idle, walk, run, and simple emote animations
- basic UI prompt
- profiler checks

## Exclude For Now

- huge map
- full GTA-style city
- combat
- police system
- wanted system
- inventory
- economy
- large NPC population
- advanced traffic simulation
- character customization
- account system
- matchmaking service
- permanent world persistence

## Map Size

Start around 300 m x 300 m.

Expand only after movement, multiplayer, vehicle, interaction, and memory targets pass.

## Player Count

Start with 2 players.

Then test 4.

Only then test 8.

Do not design for 50 or 100 players in the first prototype.
