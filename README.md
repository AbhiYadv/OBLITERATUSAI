# OBLITERATUS AI

Standalone Nexo World game prototype built with React, Three.js, React Three Fiber, and Vite.

## Quick Start

```bash
npm install
npm run dev
```

Then open the local Vite URL printed by the dev server.

## Build

```bash
npm run build
```

## Notes

- Runtime game assets are included under `public/assets`.
- Generated build output, local dependency folders, local agent config, performance reports, and raw source-art bundles are intentionally excluded from Git.
- The original raw art/source bundle was large and is not required to run the current prototype.
